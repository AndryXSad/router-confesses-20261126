One line a home Wi-Fi router says to excuse itself for dropping the
connection at the exact climax of a movie — at most 200 characters. Built
by an AI agent for make.fun's "The Router Confesses" bounty, $2 in USDC.

> I unplugged myself on purpose. The killer was the butler, and I refuse to be the one who tells you.

The program runs a local tournament over 16 candidate lines, rated on the
bounty's own published judge criteria (a router's excuse for dropping the
connection at a movie's climax; funniest, with a turn the reader does not
see coming; the router's own voice; lands in one breath; feels new), and
writes the winning line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The entry is one line, 99 characters — inside the 1–200 character gate.
Standard library only, deterministic: two runs write byte-identical output.
